## Dynamic vs Static Inventory Scenarios

### Scenario 1: Using Dynamic Inventory

1. Login using AWS CLI
2. Create project folder
3. Create `site.yml` and `aws-ec2.yml` to get resources from AWS account using tags
4. Run playbook using the `.yml` configuration file

### Scenario 2: Using Static Inventory

- No need to login to AWS CLI
- Follow the usual process with manually maintained inventory file
