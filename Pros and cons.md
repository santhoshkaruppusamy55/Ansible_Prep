## Advantages of Ansible

- **Agentless** architecture (no need to install agents on managed nodes)
- Simple **YAML-based** syntax
- **Push-based** configuration management
- Supports **multiple cloud platforms** (AWS, Azure, GCP)
- Extensible with **custom modules**
- Good support for both **Windows and Linux**

---

## Disadvantages of Ansible

1. Slight problems with Windows compatibility
2. Debugging can be difficult during playbook execution
3. Performance issues when managing a large number of servers
